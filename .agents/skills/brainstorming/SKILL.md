# Brainstorming & Collaborative Design Skill

## Purpose
Guide collaborative design and requirements refinement to turn ambiguous or high-level ideas into structured, actionable specs and implementation plans.

## Workflow

### 1. Understand Intent & Core Constraints
* Clarify the user's primary goal, target users, and key performance/aesthetic constraints.
* Identify existing patterns in the codebase (e.g. single-file HTML deliverables, "Ledger" design system, verified mechanics tables).

### 2. Explore Approaches & Trade-Offs
* Offer 2–3 distinct architectural or design approaches (e.g., lightweight inline calculator vs. standalone visual infographic).
* Compare trade-offs: complexity, maintainability, visual clarity, and computational overhead.

### 3. Interactive Alignment
* Present design mockups, formula flowcharts, or wireframe layouts using ASCII/markdown.
* Ask concise, targeted questions to resolve any remaining ambiguities.

### 4. Produce a Concrete Spec
* Synthesize decisions into a clear specification:
  - User flow & UI controls
  - Formula pipeline & data dependencies
  - Edge cases (e.g. missing stats, cap limits, level scaling)
  - Verification & testing criteria
