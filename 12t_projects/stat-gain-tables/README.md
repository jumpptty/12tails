# 12 Tails — Class Stat-Gain Tables (per level)

Twelve **portrait table infographics** (one per class) listing the **exact stat gained from leveling at every
level, 1 → 120**, for all 8 stats. Open the `.svg` files in a browser or VS Code's preview (self-contained, no deps).

## How to read a table
- **Rows** = character level 1–120. **Columns** = the 8 stats (ATK, DEF, AGI, VIT, MAG, CHA, TAL, LCK).
- **Each cell = the total points that stat has gained from leveling by that level** (cumulative).
- A cell's number is **colored/bold on the levels where that stat ticks up (+1)** and dim grey when unchanged —
  so you can see both the running total and exactly which levels grant a point. (Each stat rises by 0 or 1 per
  level, since the per-level rate `(base+3)·0.083` is always < 1.)
- The header shows each stat's class **base**; the footer shows the **Lv120 total**.

## Formula (verified)
```
gain(lv, base) = floor( (lv − 1) · (base + 3) · 0.083 )      // CharacterData.cs:515
```
Computed from each class's fixed template base stats (`CharacterData.getTypeStat`, CharacterData.cs:218–493),
so it is identical for every character of a class and stacks on top of allocated base stats, gear `att[i]`, and
passive-skill bonuses (see `../../12t_reference/12Tails-Mechanics-Reference.md`).
