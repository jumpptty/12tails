# Bible Deliverable Guidelines (`12t_projects/bible/`)

This rulebook was split on 2026-10-05 so Claude Code can load each part only when it is needed. The text is unchanged and lives in these files; read them directly:

1. **Always first:** [CLAUDE.md](CLAUDE.md) in this folder (file safety, changelog gate, validator, design basics).
2. player text (desc, change notes, status popups, glossary): [../../.claude/skills/bible-desc-writing/SKILL.md](../../.claude/skills/bible-desc-writing/SKILL.md). Read when writing or editing any player-facing Thai text in 12t_projects/bible/index.html: a skill card desc, a server changeNote, a STATUS_DESC_MAP / STATUS_DESC_SERVER popup, a mechanic glossary entry, reach/range wording, skill-name links. Covers the desc house style, markup tokens (**, __, [status], ^^term^^) and what to leave out.
3. skill card schema and card fields: [../../.claude/skills/bible-card-fields/SKILL.md](../../.claude/skills/bible-card-fields/SKILL.md). Read when adding a new skill card or adding/changing fields on a SKILLS card in 12t_projects/bible/index.html: card schema (active/passive), stat chips (lckProc labels, secondary chips, chipCols), tooltipNote, bbBug, liveCheck, durAdjust, dmgGroups basics, card order, compatSkills links.
4. damage formulas, ranges and the Test simulator: [../../.claude/skills/bible-damage-model/SKILL.md](../../.claude/skills/bible-damage-model/SKILL.md). Read when changing how a Bible skill card computes damage: dmg formulas, Raw/Final ranges, the Test simulator (rollOneHit, calcRangeFor), crit (critProc, crit view, critProc.post), purple Effect Damage (effectProc, effectDamageDep), LCK-difference damage, rawModel cards (Rabbit, Sheep, Chameleon, Panda), dmgMult, TTO no-LCK rolls, Cat Power, Open Wound, Panda SP/target inputs.
5. skill details page UI and behaviour: [../../.claude/skills/bible-skill-page-ui/SKILL.md](../../.claude/skills/bible-skill-page-ui/SKILL.md). Read when changing the skill details page behaviour or layout in 12t_projects/bible/index.html: the dependency strip and dep toggles (depSink, DEP_EXCLUSIVE, ordering), the delta motion (light balls, flips, pings, heroSnapshot/heroDelta), the player/enemy stat panels and class badge, stat-input glow, phone layout, deep links (#skill-details/...), the Buff/Debuff popup and server toggles.
6. other hub tools (menu, monster stats, boss guide, BB issues, CHA/AGI optimizer): [../../.claude/skills/bible-hub-tools/SKILL.md](../../.claude/skills/bible-hub-tools/SKILL.md). Read when working on a Bible hub tool other than the skill details page: the main menu tiles and backdrop art (TOOLS art, TOOL_ART), the monster stats page, the boss guide, the BB issues page (BUG และ คำอธิบายผิดๆ), or the CHA/AGI optimizer.
7. skill research and verification pipeline: [../../.claude/skills/bible-skill-research/SKILL.md](../../.claude/skills/bible-skill-research/SKILL.md). Read when researching a 12 Tails skill from DecompiledSource for the Bible (the /sd workflow): dead-code verification gate, active and passive source extraction, the review table, approval gates, and summon / companion / mercenary / mount card rules.

Edit those files, not this index, when a rule changes.
