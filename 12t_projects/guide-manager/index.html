กำลังโหลด…

index.html มีงานค้างที่ยังไม่ได้ commit (เช่นงานของ Claude) จึงยังทำรายการไม่ได้ รอให้งานนั้นเสร็จก่อน

ใส่กุญแจ GitHub (ครั้งแรกครั้งเดียว)

  1. เปิด หน้าสร้างกุญแจของ GitHub (Fine-grained token)
  2. Repository access เลือก Only select repositories แล้วเลือก 12tails จากนั้นที่ Permissions ให้ Actions: Read and write
  3. กด Generate token แล้วคัดลอกกุญแจ (ขึ้นต้นด้วย github_pat_) มาวางด้านล่าง

กุญแจเก็บไว้ในเบราว์เซอร์เครื่องนี้เท่านั้น และส่งไปที่ GitHub เท่านั้น ใครเปิดหน้านี้โดยไม่มีกุญแจจะแก้อะไรไม่ได้
