# Dependency Icon Strip Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move every dependency icon on a Skill Details card out of the chips, headers, description and KO badge into one strip under the description. Each strip item shows the icon, the dep's name and an effect tag.

**Architecture:** A per-render "sink" (`depSink`, a `Map` keyed by `dep.id`) collects buttons. The existing helpers (`renderDmgToggle`, `renderDmgRankToggle`, `renderDepBlock`) and the custom Cat buttons add to the sink and return `""`; each call site passes the tag for what it changes. `renderDepStrip()` draws the strip once, when the hero HTML is assembled. The buttons keep their `data-dep-*` attributes, so the existing click handlers keep working.

**Tech Stack:** a single self-contained HTML file (`12t_projects/bible/index.html`, ~14 MB, edited only through Node scratch patch scripts) and the Node validator `scripts/validate_skills.js` (a `vm` sandbox with a fake DOM; checks read rendered HTML strings).

**Spec:** `docs/superpowers/specs/2026-09-26-dep-strip-design.md`
